# Machine Learning Teaching Labs

Repositório didático com laboratórios de Python, dados e machine learning para ensino técnico, tutoria e docência.

## Objetivo

Organizar notebooks e exercícios práticos para demonstrar capacidade de ensinar conceitos de aprendizado de máquina com clareza, reprodutibilidade e boas práticas.

## Conteúdos planejados

- Introdução a pandas e NumPy
- Regressão linear
- Classificação com k-NN, árvores e regressão logística
- Métricas: acurácia, precisão, recall, F1, ROC/AUC
- Validação cruzada
- Overfitting e regularização
- Perceptron/PLA
- Introdução a redes neurais

## Datasets

Usar apenas datasets públicos clássicos ou sintéticos: Iris, Wine, Breast Cancer, Digits, Titanic ou dados gerados por scikit-learn.
